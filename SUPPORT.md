# Support

Where to take what.

| You have | Go to |
|---|---|
| A bug, or something that behaves differently from what the documentation says | [Open an issue](https://github.com/rajo69/ledgerkb/issues/new/choose). Include the output of `lkb doctor`, which contains no secrets |
| A question about how to do something | [Discussions](https://github.com/rajo69/ledgerkb/discussions) |
| A security vulnerability | [A private advisory](https://github.com/rajo69/ledgerkb/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md) |
| An idea, or a disagreement with a design decision | An issue labelled `needs discussion`, or a Discussions thread. The reasoning behind most decisions is in [`docs/design/`](docs/design/) |
| A change you want to make | [CONTRIBUTING.md](CONTRIBUTING.md) |

One maintainer, so the promise is a first response within seven days rather than
same-day support. It is a promise that gets kept.
